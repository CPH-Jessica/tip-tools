The November desk needs its own server.

This page is part of the static website. The writing ledger is the Node.js app in this folder. It keeps one shared SQLite file for the room. GitHub Pages publishes files. It does not start that server, so this address is not a shared board.

Writers log their own November 1–30 days when the Node process is running. A blank day stays blank. The room sees display names, units, and totals. Notes and edit keys stay with the writer and the keeper.

Nothing on this page is a member list. The repository copy has an empty import shape and no runtime database.

What this folder is

Run it on a computer you control.

On your own machine

  • Node.js 22.13 or newer, and npm
  • From november-accountability/: npm install
  • Copy .env.example to .env and set ADMIN_TOKEN there before any import
  • npm start listens on 127.0.0.1:8742
  • The ledger file is data/tracker.sqlite, created at startup and left out of git

If the room will open it

Host the Node process yourself, behind HTTPS, on a hostname that forwards to this app at the origin root. Keep the SQLite file on persistent disk. Set SITE_ACCESS_CODE, and set COOKIE_SECURE=1 only on HTTPS. Leave HOST on loopback until that private host is ready. Steps and the privacy rules are in the folder README.
